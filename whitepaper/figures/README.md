# Figure sources

memcomp-paths.svg shows where memcomp stores a reclaimed page and how a
fault restores it. It is drawn by ../plot_design.py and has no data
inputs. Section 2 of the paper covers store failure and entry lifetime.

timing-ratios.svg and w4-writeback-readback.svg show the formal 965-job
comparison. They are generated by ../plot_results.py, which also writes
../evaluation-tables.md. The script reads three files from the published
post-processing outputs of that collection:

- E4-presentation-table.csv: the paired decisions, copied as they are;
- paired-summary.csv: paired candidate and reference medians;
- w1-pageout.csv: per-boot W1 memory observations.

The figures show favorable, unfavorable and undecided rows alike. The
script does not judge any decision itself. A row whose pairs are all
valid and point the same way in at least 8 of 10 rounds (5 of 5 for
five-round workloads), but whose difference is below the reference
spread, is drawn hollow in that direction's color. Its E.4 decision is
unchanged.

From the repository root, with matplotlib installed:

```sh
python3 -B whitepaper/plot_design.py
python3 -B whitepaper/plot_results.py --summary <post-965-summary>
```

`<post-965-summary>` is the directory that holds the three files above.
The SVGs omit timestamp metadata and use a fixed identifier salt. An
optional `--preview-dir <dir>` writes review-only PNGs. Different
matplotlib or font versions can change the bytes without changing the
plotted values.

Early generated-content results were withdrawn and are not plotted.
Smoke, canary and offline codec-size data are not comparison data.

The figures and ../evaluation-tables.md are available under
GPL-2.0-only or CC-BY-4.0, like the whitepaper. They carry no license
header because they are regenerated output.
